# python-week2-Making-Decisions-Repeating-Tasks-in-Python
Making Decisions &amp; Repeating Tasks in Python
Student Grade Calculator
About the Project

The Student Grade Calculator is a beginner-friendly Python project that accepts a student's name and marks, calculates the grade, and displays an encouraging message.

This project was created as part of Week 2: Making Decisions & Repeating Tasks in Python.

Features
Accepts the student's name and marks.
Calculates grades using if-elif-else statements.
Validates marks between 0 and 100.
Uses a while loop to handle invalid inputs.
Uses functions to organize reusable code.
Handles invalid numeric input using try-except.
Displays a grade-specific encouraging message.
Grading System
Marks	Grade
90–100	A
80–89	B
70–79	C
60–69	D
0–59	F
Technologies Used
Python 3
VS Code or any Python editor
Git and GitHub
How to Run
Install Python 3.
Download or clone this repository.
Open a terminal in the project folder.
Run the command:

python grade_calculator.py

On some systems, use python3 grade_calculator.py.

Enter the student's name and marks when prompted.
Example
text
Enter student name: Priya
Enter marks (0-100): 85

RESULT FOR PRIYA
Marks: 85/100
Grade: B
Message: Very Good! Keep it up! 👍




Conclusion

This project demonstrates how Python can make decisions, repeat operations, validate user input, and organize code using functions.
